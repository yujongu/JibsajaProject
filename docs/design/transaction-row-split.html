Reading the mockups

What to look for

The left edge is the scan line

Run your eye straight down the left edge of each frame without reading. Layouts 1 and 3 give that edge the most continuous colour; layout 5 breaks it, because the band sits at the top of each card instead of the side. If category-first scanning is the goal, that difference matters more than anything inside the row.

Text indent is a real cost

Every pixel of block is a pixel the description loses. On a 360px phone, layout 1 starts the title 102px in and 스타벅스 아메리카노 is already clipping; layout 2 starts it at 60px and nothing clips. Check the longest titles, not the short ones.

Trade rows still read flat

Unchanged from round two: Buy #0055B2 and Deposit #059669 are single constants with no dark variant, so even at Strong their blocks barely lift off the navy card. Fixing _typeColor to use light/dark pairs is a small edit worth making alongside whichever layout wins.
