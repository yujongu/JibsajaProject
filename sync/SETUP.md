# Jibsaja — Google Sheets Sync Setup

Two-way sync between your Google Sheet and Firestore via Apps Script.

---

## Step 1 — Create a Service Account

1. Go to [console.cloud.google.com](https://console.cloud.google.com)
2. Select project **jibsaja-4a970**
3. Menu → **IAM & Admin** → **Service Accounts** → **Create Service Account**
4. Name: `jibsaja-sheets-sync` → click **Create and Continue**
5. Role: search and select **Cloud Datastore User** → **Continue** → **Done**
6. Click the new service account → **Keys** tab → **Add Key** → **Create new key** → **JSON**
7. Save the downloaded `.json` file — you'll paste its contents in Step 3

---

## Step 2 — Open Apps Script in your Sheet

1. Open your Google Sheet
2. **Extensions** → **Apps Script**
3. Delete any existing code in `Code.gs`
4. Copy and paste the entire contents of `sync/Code.gs` from this project
5. Click **Save** (💾)

---

## Step 3 — Store the Service Account Key

In Apps Script:

1. Left sidebar → **Project Settings** (⚙️) → **Script Properties**
2. Click **Add script property**
3. Property name: `SERVICE_ACCOUNT_KEY`
4. Value: paste the **entire JSON content** of the key file you downloaded in Step 1
5. Click **Save script properties**

---

## Step 4 — Enable Sync in the App

1. Open the Jibsaja app
2. Dashboard → tap the **⚙️ Settings** icon (top right)
3. Toggle **Enable Sync** to ON
4. This writes `{ enabled: true }` to Firestore — the Apps Script checks this before doing anything

---

## Step 5 — Install Triggers

Back in Apps Script:

1. In the function dropdown (top toolbar), select **`setupTriggers`**
2. Click **Run** ▶
3. Approve the permissions popup (allow the script to access Sheets and make network requests)
4. You should see "Triggers installed successfully" in the log

This creates two triggers:
- **onSheetEdit** — fires instantly when you edit the Accounts or Transactions tab → writes to Firestore
- **pollAll** — fires every 5 minutes → reads Firestore and updates the Sheet + pushes Holdings to Firestore

---

## Step 6 — Run the Initial Sync

This seeds Firestore with all your existing Sheet data:

1. Select function **`initialSync`** → click **Run** ▶
2. Check the logs (View → Logs) — you should see row counts and "Initial sync complete"
3. Open the app — your accounts, cards, transactions, and holdings should appear

---

## What Syncs

| Data | Direction | Source |
|------|-----------|--------|
| Accounts (Bank/Brokerage/Crypto) | ↔ Both ways | Sheet Accounts tab |
| Cards (Credit) | ↔ Both ways | Sheet Accounts tab (Type = Credit) |
| Transactions (Expense/Deposit) | ↔ Both ways | Sheet Transactions tab |
| Holdings | → Sheet → App only | Sheet Holdings tab (computed from Buy/Sell) |
| Transfers / Buy / Sell | — Skipped | Not mapped to app transactions |

## Troubleshooting

**Permission denied errors in logs**
→ The service account needs the **Cloud Datastore User** role. Check IAM in Google Cloud Console.

**"SERVICE_ACCOUNT_KEY not set" error**
→ Re-check Step 3. Make sure you pasted the full JSON (including the outer `{ }` braces).

**Sheet edits not syncing to app**
→ Check that the toggle is ON in the app. Run `isSyncEnabled_()` manually in Apps Script to test.

**Sync is disabled in Firestore (initialSync log)**
→ Turn on the toggle in the app first, then re-run `initialSync`.

**App data not showing in Sheet after 5 min**
→ Check Apps Script trigger list (left sidebar → ⏰ Triggers). Both `onSheetEdit` and `pollAll` should be listed.
